# NaviiView

**自炊した漫画を、見開きで軽快に。 / Fast reader for scanned comics.**

- 🌐 **公式サイト (Official Website)**: [https://naviiview.navii.online](https://naviiview.navii.online)
- 💬 **Discord コミュニティ**: [https://discord.gg/pxv9msDyJ](https://discord.gg/pxv9msDyJ)
- 🍎 **App Store (iPhone Duo / iPhone / iPad / Mac)**: [https://apps.apple.com/app/id6824969523](https://apps.apple.com/app/id6824969523) (¥500 / $4.99 Universal Purchase)
- 🐧 **Linux (Free)**: [Releases](https://github.com/takakix2/naviiview/releases) から AppImage / .deb / .rpm をダウンロードいただけます。

---

## 特長 / Features

- **見開きがずれない**: 見開き / 単ページ / 縦スクロール。右開き・左開きの自動/手動切り替え。
- **待たないページ送り**: スワイプ、矢印キー、トラックパッドで即座にページ切り替え。
- **ネットワークの本をそのまま**: SMB（NAS / 共有フォルダ）や S3 ストレージ上の本をダウンロードせずに直接高速ストリーミング読書。
- **多彩な対応形式**: PDF、ZIP、CBZ、RAR、CBR、7Z、CB7、TAR、CBT、LHA、LZH、EPUB、JPEG、PNG、WebP、AVIF など。
- **マルチプラットフォーム**: iOS、iPadOS、macOS、Windows（近日）、Linux。
